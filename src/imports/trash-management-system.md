Trash Management System (TrashHoop)
1.)

Improper waste segregation (biodegradable, non-biodegradable, recyclable, mixed waste) 

2.)

Residents mix biodegradable, recyclable, and non biodegradable waste, causing contamination, inefficiency, and increased landfill waste.

3.1) Target Users

Households / Residents
Garbage Collector
Barangay Official

3.2) Must have requirements (Functional Requirements):

User Registration Login (Admin and Resident access)
Waste Segregation Guide (Clear explanations of waste categories)
Admin Dashboard (Monitor report & violations)
Report Improper Disposal Feature (When someone reports improper disposal, they can attach a photo. Helps the admin verify the complaint)
Waste Category Information Page (Biodegradable. Recyclable, Residual)
CRUD Functions (Manage users, reports, record)
Garbage Route List (Garbage collectors can view which areas to collect first)
(Can mark garbage as Collected / Not Collected)

3.3) Should have requirements (Non - functional Requirements) :

Collection day (Reminder Notification or Schedule)
Violation Tracking per Household (Violation History)
Monthly Waste Monitoring Reports
Education Tips Section
Warning Notification System for report offenders





3.4) Nice to have requirements (this already includes the Dashboard of the solution) : 

Reward system for proper segregation
Points system redeemable for incentives
QR code for smart trash bins
Recycling pickup request option
Mobile app version
Announcement dashboard for everyone
Monthly payment for trash collectors (QR code or Online Payment)
